# peak-watermarker

A planned photo watermarking app for iPhone, free for good, built for one photographer: my
mom. She will pick photos she has already taken, place a text mark once, and save
watermarked copies of all of them, or let the phone choose a good spot for each photo. The
originals stay untouched, and her photos never leave the phone.

**Status: proving the install route.** There is no app code yet. The signed-off
[plan](docs/02-plan.md) has the milestones, the decisions are in the
[planning log](docs/01-planning-log.md), and what the app has to do is in
[capabilities](docs/capabilities.md). The plan is Expo (React Native), with a small Swift
and Kotlin module for the image work.
